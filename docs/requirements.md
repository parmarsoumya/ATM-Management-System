# Stage 2 – Project Requirements

## 1. Functional Requirements

### FR-01 User Login
The system shall allow a user to log in using an account number
and PIN.

### FR-02 Balance Enquiry
The system shall display the current account balance.

### FR-03 Deposit
The system shall allow the user to deposit money.

### FR-04 Withdrawal
The system shall allow the user to withdraw money after validating
the available balance.

### FR-05 PIN Change
The system shall allow the authenticated user to change the PIN.

### FR-06 Transaction History
The system shall maintain transaction records.

### FR-07 Account Information
The system shall display relevant account information.

### FR-08 File Storage
The system shall store account and transaction information using
files.

### FR-09 Linux Device Communication
The ATM application shall communicate with a Linux character device.

### FR-10 Device Operation
The Linux device component shall provide an interface representing
the ATM hardware interaction.

## 2. Non-Functional Requirements

### NFR-01 Operating System
The project shall run on Linux.

### NFR-02 Programming Language
The main application shall be implemented in C++.

### NFR-03 Driver Language
The Linux device-driver component shall use C.

### NFR-04 Reliability
The system shall handle invalid input and failed transactions.

### NFR-05 Maintainability
The project shall use a modular structure.

### NFR-06 Documentation
The project shall maintain documentation throughout development.

### NFR-07 Version Control
Git shall be used for version control.

## 3. Major Modules

1. Authentication Module
2. Account Management Module
3. Transaction Module
4. File Management Module
5. ATM Application Module
6. Linux Device Driver Module
7. Testing and Documentation Module
