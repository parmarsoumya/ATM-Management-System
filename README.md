# ATM Management System

## Description

A console-based ATM Management System developed using C++.
The project provides basic ATM operations such as login,
balance enquiry, deposit, withdrawal, PIN change and
transaction history.

## Features

- Account Login
- Balance Enquiry
- Deposit
- Withdrawal
- PIN Change
- Mini Statement
- Account Information
- Linux System Information
- File-based Data Storage
